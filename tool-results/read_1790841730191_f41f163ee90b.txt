    11→## §0. Methodology (inherited from CORE-DAG-RECONCILIATION-8 + ADR-021 Amendment 2)
    12→
    13→Per ADR-021 Amendment 2, every edge has 4 dimensions:
    14→- **edge_type**: COMPILE | RUNTIME | INTEGRATION | CAPABILITY (exactly one)
    15→- **requiredness**: REQUIRED | OPTIONAL (independent of edge_type)
    16→- **declared/verified → status**: VERIFIED | DECLARED_ONLY | UNDECLARED_VERIFIED | INVALID (derived)
    17→- **gates**: list of BUILD | RUNTIME | INTEGRATION | PRODUCTION
    18→
    19→Per ADR-021 §11, the Hub tier has TWO authoritative DAGs:
    20→- **DECLARED DAG** — from blueprint Upward/Downward/Transitive Core sections (architectural intent)
    21→- **VERIFIED DAG** — from composer.json `require` + `use SovereignStack\*` source imports (repository reality)
    22→
    23→This inventory is the **evidence base** for both DAGs. It does NOT decide direction corrections or build waves — those are Phase 2 deliverables after tech-lead review.
    24→
    25→**Status definitions (per ADR-021):**
    26→- `VERIFIED` — declared in blueprint AND verified in composer/source
    27→- `DECLARED_ONLY` — declared in blueprint, not verified in code (target may not yet be implemented)
    28→- `UNDECLARED_VERIFIED` — verified in composer/source, but not formally declared in blueprint's Upward list
    29→- `INVALID` — declared AND verified AND target does not exist in active inventory (none expected for Hub tier)

   578→- (b) the descriptor "Queue" is wrong and the target HUB-11 (Cloud Storage) is the actual intent — but this is semantically odd for "optional async write path for non-critical events" (which is a queue pattern, not cloud-storage)

   606→### Gap 4 — Bidirectional cycle HUB-08 ↔ HUB-15 — ADR-004 acyclic rule violation
   607→
   608→Two separate edges form a cycle:
   609→- `HUB-08 → HUB-15` (§5.1 row 23) — declared in HUB-15 Downward: "HUB-08 (Gateway — future dynamic `ServiceRegistry` consults HUB-15 state, replacing the static config-loaded registry)"

   617→
   618→Both being RUNTIME means neither is a COMPILE dep, so the build-order DAG remains acyclic. The runtime-call DAG may still have the cycle, but that's a documented property of the tier's operational behavior, not a build-order violation.
