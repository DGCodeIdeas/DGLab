    23→## Description
    24→CORE-02 is the dependency injection container that every other Core-tier service and every Hub-tier service is resolved through. It is the second object instantiated in the system kernel (CORE-18), immediately after the configuration loader (CORE-10) injects environment values. The container exposes a PSR-11 compliant `get()` / `has()` API so that any third-party PSR-11 consumer can use it unchanged, while also exposing a Sovereign-Stack-native `bind()` / `singleton()` / `make()` API that supports constructor autowiring via reflection, primitive bindings, interface-to-implementation mappings, and instance pre-registration.
    25→
    26→The container is intentionally minimal: the only runtime dependency is `psr/container: ^2.0`. No PHP-DI, no Symfony DI, no League Container. ADR-002 records the rationale — sovereign control of the resolution graph, minimal supply-chain surface, and the need for a compiler-pass architecture that flattens cleanly into the OPcache preload strategy described in ADR-010. The container has two distinct execution modes. In **open** mode (the default), `bind()`, `singleton()`, `instance()`, and `addCompilerPass()` mutate the service graph, and `make()` resolves reflectively at runtime. After `compile()` is invoked, the container enters **compiled** mode: all mutation methods throw `\LogicException`, registered compiler passes have already run, and `make()` operates against the (now-frozen) definition table. In a future revision, the compiled mode will read from a cached PHP array generated by a `CompiledContainerPass`; the present blueprint ships the open-mode + frozen-mode contract that the compiler pass extension point depends on.
    27→
    28→The container is **not** a service locator. Code that holds a reference to `ContainerInterface` should call `get()` only at composition roots (kernel boot, controller factories, console command factories). Application code is expected to receive its dependencies through constructor injection and remain container-agnostic. The container is **not** a reactive runtime by itself — the "Reactive" in its name refers to the planned integration with CORE-07/11/12 (SuperPHP), where `@persist`-scoped services will be resolved through this container; that integration is out of scope for this blueprint and tracked under CORE-12.

    75→
    76→### Class Map
    77→
    78→| Class | Kind | Responsibility |
    79→|---|---|---|
    80→| `ContainerInterface` | interface | Extends `Psr\Container\ContainerInterface`. Adds `bind()`, `singleton()`, `instance()`, `make()`, `addCompilerPass()`, `compile()`. This is the API surface consumed by service providers (CORE-17) and the kernel (CORE-18). |
    81→| `ContainerBuilderInterface` | interface | Read-only view over the definition table used by compiler passes: `getDefinitions()`, `getDefinition()`, `hasDefinition()`. Decouples `CompilerPassInterface` from the mutable `Container`. |
    82→| `CompilerPassInterface` | interface | Single-method `process(ContainerBuilderInterface $builder)`. Implemented by callers (e.g. CORE-17 service providers, future `CompiledContainerPass`) to rewrite the definition graph before `compile()` freezes it. |
    83→| `ServiceDefinition` | `final readonly class` | Immutable value object: `abstract` (the bound id), `concrete` (Closure, class-string, or pre-built instance), `shared` (bool, true for singletons), `tags` (list of strings). |
    84→| `Container` | `final class` | The reference implementation. Implements `ContainerInterface` and `ContainerBuilderInterface`. Owns the `$definitions`, `$instances`, `$resolving`, `$compilerPasses`, and `$compiled` state. |
    85→| `NotFoundException` | `final class extends \RuntimeException implements \Psr\Container\NotFoundExceptionInterface` | Thrown by `get()` when the id is not resolvable. |
    86→| `CircularDependencyException` | `final class extends \RuntimeException implements \Psr\Container\ContainerExceptionInterface` | Thrown by `make()` when the resolution stack detects a cycle. Constructor takes the resolution chain array. |

    88→### Interface Contracts
    89→
    90→```php
    91→<?php
    92→declare(strict_types=1);
    93→
    94→namespace SovereignStack\Core\Container;
    95→
    96→use Psr\Container\ContainerInterface as PsrContainerInterface;
    97→
    98→/**
    99→ * Sovereign Stack dependency injection container.
   100→ *
   101→ * Extends the PSR-11 {@see PsrContainerInterface} with a mutation API
   102→ * (bind/singleton/instance/addCompilerPass/compile) and a non-cached
   103→ * factory method {@see make()} that always returns a fresh instance
   104→ * (unless the binding is marked shared, in which case the first
   105→ * resolution is cached and reused).
   106→ *
   107→ * `get()` (inherited from PSR-11) and `make()` differ in one respect:
   108→ * `get()` throws {@see NotFoundException} when the id is unknown and
   109→ * cannot be autowired; `make()` throws the same exception under the
   110→ * same conditions but is permitted to construct an unregistered
   111→ * class-string by reflection when one is supplied directly.
   112→ */
   113→interface ContainerInterface extends PsrContainerInterface
   114→{
   115→    /**
   116→     * Register a binding in the container.
   117→     *
   118→     * @param string $id        The service identifier (typically an interface FQCN).
   119→     * @param mixed  $concrete  The concrete resolver. Accepts: a class-string,
   120→     *                          a {\@see \Closure} receiving ($container, $parameters),
   121→     *                          a pre-built object instance, or null (in which case
   122→     *                          $id is used as the concrete class-string).
   123→     * @param bool   $singleton When true, the first resolved instance is cached
   124→     *                          for the **worker lifetime** and returned on all subsequent
   125→     *                          {\@see make()} / {\@see get()} calls from any Fiber/Pulse.
   126→     *
   127→     *                          **Fiber runtime warning (OD-07):** Under a long-lived
   128→     *                          FrankenPHP worker, `singleton()` means "one instance
   129→     *                          shared across ALL concurrent Pulses in this worker" —
   130→     *                          including multiple tenants. If you need per-Pulse
   131→     *                          instances (the common case for repositories, request
   132→     *                          context, tenant-scoped services), use {\@see pulse()}
   133→     *                          instead. See `DGLAB-AS-OS-RUNTIME.md` §8.0.
   134→     *
   135→     * @throws \LogicException If the container has already been compiled.
   136→     */
   137→    public function bind(string $id, mixed $concrete = null, bool $singleton = false): void;
   138→
   139→    /**
   140→     * Convenience wrapper for {\@see bind()} with $singleton = true.
   141→     *
   142→     * **Scope:** worker-lifetime (shared across all Pulses in this worker process).
   143→     * For per-Pulse instances, use {\@see pulse()}.
   144→     */
   145→    public function singleton(string $id, mixed $concrete = null): void;
   146→
   147→    /**
   148→     * Bind a concrete value to the current Fiber's Pulse scope (Shape C).
   149→     *
   150→     * **Semantic contract (ratified per ADR-021 Amendment 2 + tech-lead decision 2026-10-01):**
   151→     *
   152→     * `pulse($abstract, $value)` is a **request-time, Fiber-local value-binding operation**.
   153→     * It is NOT a boot-time factory registration. The `$value` IS the instance —
   154→     * `make($abstract)` returns this value directly for the current Fiber.
   155→     *
   156→     * The binding and its resulting instance are scoped to the current Pulse/Fiber
   157→     * and must NEVER become visible to another Fiber.
   158→     *
   159→     * **State-transition table:**
   160→     *
   161→     * | Operation       | Current Fiber pulse state | Cached pulse instance | Resolution result |
   162→     * |-----------------|---------------------------|-----------------------|-------------------|
   163→     * | `pulse(A, x)`   | A → x (set)               | (none or invalidated) | —                 |
   164→     * | `make(A)`       | A → x                     | x (cached)            | x                 |
   165→     * | `pulse(A, y)`   | A → y (overwrite)         | (invalidated)         | —                 |
   166→     * | `make(A)`       | A → y                     | y (cached)            | y                 |
   167→     *
   168→     * A new `pulse()` call for an already-resolved ID **invalidates the cached
   169→     * pulse instance for that ID in the CURRENT Fiber only** (not other Fibers).
   170→     * The next `make()` returns the new value.
   171→     *
   172→     * **make() precedence (Shape C):**
   173→     *
   174→     * 1. Current Fiber's pulse definitions → if defined, the pulse value IS the instance
   175→     * 2. Current Fiber's pulse instances cache → if already resolved, return cached
   176→     * 3. Worker-scoped instances cache → singletons (shared across Fibers)
   177→     * 4. Global definitions → resolve and cache (per-Fiber for transient, global for singleton)
   178→     * 5. Not found → throw NotFoundException
   179→     *
   180→     * Pulse-scoped bindings take PRECEDENCE over singletons for the current Fiber.
   181→     * A `pulse(A, value)` shadows a `singleton(A, factory)` for the current Fiber.
   182→     *
   183→     * **Edge cases (12 — all explicitly defined):**
   184→     *
   185→     * 1. **pulse() outside a Fiber:** Throws `ContainerException`. `pulse()` requires
   186→     *    a current Fiber context. If called outside a Fiber (e.g., during boot), there
   187→     *    is no Pulse scope to bind to. Use `bind()` or `singleton()` for boot-time
   188→     *    registration.
   189→     *
   190→     * 2. **make() before pulse():** If A is not in the current Fiber's pulse scope,
   191→     *    `make(A)` falls through to steps 2-5 (pulse cache → singleton → definition →
   192→     *    NotFoundException). A pulse-scoped binding is NOT required to exist for `make()`
   193→     *    to succeed — it only takes precedence when it exists.
   194→     *
   195→     * 3. **Repeated pulse() calls:** `pulse(A, x)` then `pulse(A, y)` → the second call
   196→     *    overwrites the first. The pulse scope has A → y. If a cached instance exists,
   197→     *    it is invalidated (current Fiber only).
   198→     *
   199→     * 4. **pulse() after resolution/caching:** `pulse(A, y)` after `make(A)` returned $x →
   200→     *    invalidates $x in the current Fiber. Next `make(A)` returns $y. This is because
   201→     *    `pulse()` is the authoritative source of truth for the current Fiber's value.
   202→     *
   203→     * 5. **singleton() interaction:** `singleton(A, factory)` is worker-scoped (global).
   204→     *    `pulse(A, value)` is Fiber-scoped. `make(A)` checks pulse scope FIRST — so a
   205→     *    pulse-scoped binding shadows a singleton for the current Fiber. This is useful
   206→     *    for testing (mock a singleton per-request) and for request-scoped overrides
   207→     *    (e.g., RequestContext per-Pulse).
   208→     *
   209→     * 6. **Nested Fibers:** A child Fiber inherits the global container state (singletons,
   210→     *    frozen bindings, compiler passes, container configuration) but has its OWN pulse
   211→     *    scope. The parent's pulse bindings are NOT visible to the child. Clean isolation.
   212→     *
   213→     * 7. **Fiber termination and GC:** When a Fiber terminates, its entries in the
   214→     *    `WeakMap<Fiber, ...>` are eligible for GC. The pulse scope and cached instances
   215→     *    are automatically evicted. No manual cleanup needed. This is the structural
   216→     *    guarantee of Fiber isolation.
   217→     *
   218→     * 8. **Fiber reuse:** If a Fiber is reused (started again after termination), it gets
   219→     *    a fresh pulse scope. Previous pulse bindings are gone (GC'd). The Fiber must
   220→     *    `pulse()` again to establish new bindings.
   221→     *
   222→     * 9. **Child Fiber inheritance/isolation:** Child Fiber inherits: global singletons,
   223→     *    frozen bindings, compiler passes, container configuration. Child Fiber does NOT
   224→     *    inherit: parent's pulse bindings, parent's pulse instances, parent's resolution
   225→     *    stack. Clean isolation invariant: **No pulse-local value may cross a Fiber
   226→     *    boundary unless explicitly passed through an application-level mechanism.**
   227→     *
   228→     * 10. **make() precedence:** See the 5-step precedence above. Pulse definitions (step 1)
   229→     *     take precedence over everything else for the current Fiber.
   230→     *
   231→     * 11. **New pulse invalidates cached instance:** YES. `pulse(A, y)` after `make(A)`
   232→     *     returned $x → invalidates $x in the CURRENT Fiber only. Next `make(A)` returns $y.
   233→     *     This is because `pulse()` is the authoritative source of truth for the current
   234→     *     Fiber's value.
   235→     *
   236→     * 12. **Pulse-scoped object resolving a singleton:** A pulse-scoped object CAN resolve
   237→     *     singletons. For example, `pulse(Repository::class, $repo)` where `$repo` was
   238→     *     constructed with `make(DBAL::class)` — the DBAL is a singleton (worker-scoped),
   239→     *     and the pulse-scoped Repository can use it. Singletons are global; pulse-scoped
   240→     *     objects can reference them. The reverse is NOT safe: a singleton should NOT
   241→     *     reference a pulse-scoped object (the singleton outlives the Pulse).
   242→     *
   243→     * **Implementation note (S-003/S-004 remediation direction):**
   244→     *
   245→     * The current implementation writes `pulse()` to global `$definitions[$id]` instead
   246→     * of a per-Fiber `WeakMap $pulseDefinitions`. The fix: add `private \WeakMap
   247→     * $pulseDefinitions` and redirect `pulse()`/`make()` to consult it per-Fiber. The
   248→     * existing `$pulseInstances` WeakMap (for cached instances) is already correct —
   249→     * only the definitions table is missing the per-Fiber scoping.
   250→     *
   251→     * @param string $id       The service identifier.
   252→     * @param mixed  $concrete The concrete VALUE to bind to the current Fiber's Pulse scope.
   253→     *                          This IS the instance returned by `make($id)` — not a factory.
   254→     *
   255→     * @throws \LogicException If the container has already been compiled.
   256→     * @throws \SovereignStack\Core\Container\ContainerException If called outside a Fiber context.
   257→     */
   258→    public function pulse(string $id, mixed $concrete = null): void;
   259→
   260→    /**
   261→     * Register a pre-built object instance as a shared binding.
   262→     *
   263→     * The instance is stored in the resolved cache immediately; subsequent
   264→     * {@see get()} / {@see make()} calls return the same object identity.
   265→     *
   266→     * @param string $id       The service identifier.
   267→     * @param object $instance The instance to register.
   268→     *
   269→     * @throws \LogicException If the container has already been compiled.
   270→     */
   271→    public function instance(string $id, object $instance): void;
   272→
   273→    /**
   274→     * Resolve a service from the container.
   275→     *
   276→     * If $id refers to a shared binding that has already been resolved,
   277→     * the cached instance is returned. Otherwise a new instance is
   278→     * constructed by reflection (autowiring) using $parameters for any
   279→     * constructor arguments that cannot be resolved from the container.
   280→     *
   281→     * @param string  $id         The service identifier or a class-string.
   282→     * @param array<string,mixed> $parameters Positional-or-named constructor
   283→     *                            overrides. Named keys match parameter names;
   284→     *                            integer keys match parameter position.
   285→     *
   286→     * @return mixed The resolved service instance.
   287→     *
   288→     * @throws CircularDependencyException If $id is part of a resolution cycle.
   289→     * @throws NotFoundException           If $id cannot be resolved (unknown
   290→     *                                     class, non-instantiable class, or
   291→     *                                     an unresolved primitive constructor
   292→     *                                     argument with no default).
   293→     */
   294→    public function make(string $id, array $parameters = []): mixed;
   295→
   296→    /**
   297→     * Register a compiler pass to run during {@see compile()}.
   298→     *
   299→     * Compiler passes receive a read-only {@see ContainerBuilderInterface}
   300→     * view of the definition table and may rewrite definitions (by calling
   301→     * {@see bind()} on the underlying container) before the container is
   302→     * frozen.
   303→     *
   304→     * @throws \LogicException If the container has already been compiled.
   305→     */
   306→    public function addCompilerPass(CompilerPassInterface $pass): void;
   307→
   308→    /**
   309→     * Freeze the container.
   310→     *
   311→     * Runs all registered compiler passes in registration order, then
   312→     * sets the `$compiled` flag. After this returns, any call to
   313→     * {@see bind()}, {@see singleton()}, {@see instance()}, or
   314→     * {@see addCompilerPass()} throws {@see \LogicException}.
   315→     *
   316→     * Idempotent: calling compile() on an already-compiled container
   317→     * returns immediately without re-running passes.
   318→     */
   319→    public function compile(): void;
   320→}

   384→```php
   385→<?php
   386→declare(strict_types=1);
   387→
   388→namespace SovereignStack\Core\Container;
   389→
   390→/**
   391→ * Immutable description of a single service binding.
   392→ *
   393→ * A `readonly class` (PHP 8.2+) — all properties are implicitly readonly.
   394→ * Once constructed, a definition cannot be mutated; compiler passes that
   395→ * need to alter a binding must replace it by calling `bind()` with the
   396→ * same id.
   397→ */
   398→final readonly class ServiceDefinition
   399→{
   400→    /**
   401→     * @param string       $abstract     The service identifier (the id passed to bind()).
   402→     * @param mixed        $concrete     A class-string, a Closure receiving
   403→     *                                   ($container, $parameters), or a pre-built
   404→     *                                   object instance.

   441→```php
   442→<?php
   443→declare(strict_types=1);
   444→
   445→namespace SovereignStack\Core\Container;
   446→
   447→/**
   448→ * Thrown by {@see ContainerInterface::make()} when the resolution stack
   449→ * detects that the requested service is already being resolved higher up
   450→ * the call chain — i.e. a circular dependency.
   451→ *
   452→ * The full resolution chain is preserved in the exception so callers can
   453→ * log, display, or assert on it. The chain always ends with the id that
   454→ * closed the cycle, e.g. `[A, B, C, B]` for the cycle B → C → B reached
   455→ * while resolving A.
   456→ */
   457→final class CircularDependencyException extends \RuntimeException implements \Psr\Container\ContainerExceptionInterface
   458→{
   459→    /**
   460→     * @param list<string>  $chain    The resolution chain, in order, ending
   461→     *                                with the id that closed the cycle.
   462→     * @param string|null   $message  Optional custom message; defaults to
   463→     *                                a human-readable rendering of $chain.
   464→     * @param int           $code     Numeric code.
   465→     * @param \Throwable|null $previous Previous exception, if any.
   466→     */
   467→    public function __construct(
   468→        private readonly array $chain,
   469→        ?string $message = null,
   470→        int $code = 0,
   471→        ?\Throwable $previous = null,
   472→    ) {
   473→        parent::__construct(
   474→            $message ?? 'Circular dependency detected: ' . implode(' -> ', $chain),
   475→            $code,
   476→            $previous,
   477→        );
   478→    }
   479→
   480→    /**
   481→     * Convenience factory.
   482→     *
   483→     * @param list<string> $chain
   484→     */
   485→    public static function fromChain(array $chain): self
   486→    {
   487→        return new self($chain);
   488→    }
   489→
   490→    /**
   491→     * @return list<string>
   492→     */
   493→    public function getResolutionChain(): array
   494→    {
   495→        return $this->chain;
   496→    }
   497→}

   500→### Reference Implementation
   501→
   502→The following class is the complete, copy-pasteable `Container` implementation. It compiles against PHP 8.3 with only `psr/container: ^2.0` as runtime dependency. Drop it into `packages/core/container/src/Container.php` alongside the interface files above and `composer dump-autoload` will pick it up unchanged.
   503→
   504→```php
   505→<?php
   506→declare(strict_types=1);
   507→
   508→namespace SovereignStack\Core\Container;
   509→
   510→/**
   511→ * Reference implementation of {@see ContainerInterface} and
   512→ * {@see ContainerBuilderInterface}.
   513→ *
   514→ * State:
   515→ *   - $definitions    : id -> ServiceDefinition (the binding table)
   516→ *   - $instances      : id -> resolved object (shared-instance cache)
   517→ *   - $pulseInstances : WeakMap<Fiber, array<string, mixed>> (auto-evicts on Fiber GC)
   518→ *   - $resolving      : id -> true (the resolution stack; presence == on stack)
   519→ *   - $compilerPasses : list of passes to run during compile()
   520→ *   - $compiled       : freeze flag; mutation methods assert false before running
   521→ *
   522→ * Resolution flow (see also the sequence diagram in this blueprint):
   523→ *   make(A) ->
   524→ *     1. if A in $instances -> return cached object
   525→ *     1b. if A is pulse-scoped && current Fiber -> check WeakMap[Fiber][A]
   526→ *     2. if A in $resolving -> throw CircularDependencyException(chain)
   527→ *     3. push A onto $resolving
   528→ *     4. try { build(concrete) } finally { pop A from $resolving }
   529→ *     5. if shared -> cache in $instances
   530→ *     5b. if pulse-scoped && current Fiber -> cache in WeakMap[Fiber][A]
   531→ *     6. return object
   532→ *
   533→ * Cycle detection is resolution-time, not graph-time. This is deliberate:
   534→ * a graph-time analysis would have to walk every Closure binding (which may
   535→ * be opaque) and every constructor argument of every class. Resolution-time
   536→ * detection via a stack + finally is O(depth) per resolution, never
   537→ * stack-overflows, and surfaces the exact chain that closed the cycle.
   538→ */
   539→final class Container implements ContainerInterface, ContainerBuilderInterface
   540→{
   541→    /** @var array<string, ServiceDefinition> */
   542→    private array $definitions = [];
   543→
   544→    /** @var array<string, mixed> Worker-scoped instance cache (singleton + instance). */
   545→    private array $instances = [];
   546→
   547→    /**
   548→     * Pulse-scoped instance cache, keyed on the Fiber object itself.
   549→     * WeakMap<Fiber, array<string, mixed>> — auto-evicts when Fiber is GC'd.
   550→     * Outside any Fiber context, pulse-scoped bindings behave as transient.
   551→     */
   552→    private \WeakMap $pulseInstances;
   553→
   554→    /** @var array<string, true> */
   555→    private array $resolving = [];
   556→
   557→    /** @var list<CompilerPassInterface> */
   558→    private array $compilerPasses = [];
   559→
   560→    private bool $compiled = false;
   561→
   562→    public function __construct()
   563→    {
   564→        $this->pulseInstances = new \WeakMap();
   565→    }
   566→
   567→    public function bind(string $id, mixed $concrete = null, bool $singleton = false): void
   568→    {
   569→        $this->assertNotCompiled();
   570→
   571→        $concrete ??= $id;
   572→
   573→        $this->definitions[$id] = new ServiceDefinition(
   574→            abstract: $id,
   575→            concrete: $concrete,
   576→            shared: $singleton,
   577→            tags: [],
   578→        );
   579→    }
   580→
   581→    public function singleton(string $id, mixed $concrete = null): void
   582→    {
   583→        $this->bind($id, $concrete, true);
   584→    }
   585→
   586→    public function pulse(string $id, mixed $concrete = null): void
   587→    {
   588→        $this->assertNotCompiled();
   589→
   590→        $concrete ??= $id;
   591→
   592→        $this->definitions[$id] = new ServiceDefinition(
   593→            abstract: $id,
   594→            concrete: $concrete,
   595→            shared: false,
   596→            pulseScoped: true,
   597→            tags: [],
   598→        );
   599→    }
   600→
   601→    public function instance(string $id, object $instance): void
   602→    {
   603→        $this->assertNotCompiled();
   604→
   605→        $this->instances[$id] = $instance;
   606→        $this->definitions[$id] = new ServiceDefinition(
   607→            abstract: $id,
   608→            concrete: $instance,
   609→            shared: true,
   610→            tags: [],
   611→        );
   612→    }
   613→
   614→    public function make(string $id, array $parameters = []): mixed
   615→    {
   616→        // 1. Resolved-instance cache (worker-scoped).
   617→        if (array_key_exists($id, $this->instances)) {
   618→            return $this->instances[$id];
   619→        }
   620→
   621→        // 1b. Pulse-scoped cache (WeakMap — auto-evicts on Fiber GC).
   622→        $definition = $this->definitions[$id] ?? null;
   623→        if ($definition !== null && $definition->pulseScoped) {
   624→            $fiber = \Fiber::getCurrent();
   625→            if ($fiber !== null && isset($this->pulseInstances[$fiber][$id])) {
   626→                return $this->pulseInstances[$fiber][$id];
   627→            }
   628→        }
   629→
   630→        // 2. Cycle detection — resolution-time, never stack-overflows.
   631→        if (isset($this->resolving[$id])) {
   632→            $chain = array_keys($this->resolving);
   633→            $chain[] = $id;
   634→            throw CircularDependencyException::fromChain($chain);
   635→        }
   636→
   637→        // 3. Push onto the resolution stack.
   638→        $this->resolving[$id] = true;
   639→
   640→        try {
   641→            $concrete = $definition?->concrete ?? $id;
   642→
   643→            // 4. Build by concrete type.
   644→            $object = $this->build($concrete, $parameters);
   645→        } finally {
   646→            // 5. Always pop, even on exception — no state leak.
   647→            unset($this->resolving[$id]);
   648→        }
   649→
   650→        // 6. Cache shared singletons (worker-scoped).
   651→        if ($definition !== null && $definition->shared) {
   652→            $this->instances[$id] = $object;
   653→        }
   654→
   655→        // 6b. Cache pulse-scoped instances (per-Fiber, via WeakMap).
   656→        if ($definition !== null && $definition->pulseScoped) {
   657→            $fiber = \Fiber::getCurrent();
   658→            if ($fiber !== null) {
   659→                $this->pulseInstances[$fiber][$id] = $object;
   660→            }
   661→        }
   662→
   663→        return $object;
   664→    }
   665→
   666→    /**
   667→     * PSR-11 get(): throws NotFoundException on unknown ids.
   668→     *
   669→     * Unlike make(), get() refuses to construct an arbitrary class-string
   670→     * that has not been explicitly bound or registered via instance().
   671→     * This matches the PSR-11 contract that get() must throw if the id
   672→     * is not "known" to the container.
   673→     */
   674→    public function get(string $id): mixed
   675→    {
   676→        if (!$this->has($id)) {
   677→            throw new NotFoundException("No service registered for id [$id].");
   678→        }
   679→
   680→        return $this->make($id);
   681→    }
   682→
   683→    /**
   684→     * PSR-11 has(): true if the id is bound, pre-instantiated, or
   685→     * refers to an autoloadable class (the latter supports autowiring
   686→     * of unregistered class-strings via make()).
   687→     */
   688→    public function has(string $id): bool
   689→    {
   690→        return array_key_exists($id, $this->instances)
   691→            || array_key_exists($id, $this->definitions)
   692→            || class_exists($id);
   693→    }
   694→
   695→    public function addCompilerPass(CompilerPassInterface $pass): void
   696→    {
   697→        $this->assertNotCompiled();
   698→        $this->compilerPasses[] = $pass;
   699→    }
   700→
   701→    public function compile(): void
   702→    {
   703→        // Idempotent: a second call is a no-op.
   704→        if ($this->compiled) {
   705→            return;
   706→        }
   707→
   708→        foreach ($this->compilerPasses as $pass) {
   709→            $pass->process($this);
   710→        }
   711→
   712→        $this->compiled = true;
   713→    }
   714→
   715→    // ----- ContainerBuilderInterface -----
   716→
   717→    public function getDefinitions(): array
   718→    {
   719→        return $this->definitions;
   720→    }
   721→
   722→    public function getDefinition(string $id): ServiceDefinition
   723→    {
   724→        if (!array_key_exists($id, $this->definitions)) {
   725→            throw new NotFoundException("No definition registered for id [$id].");
   726→        }
   727→
   728→        return $this->definitions[$id];
   729→    }
   730→
   731→    public function hasDefinition(string $id): bool
   732→    {
   733→        return array_key_exists($id, $this->definitions);
   734→    }
   735→
   736→    // ----- Internals -----
   737→
   738→    /**
   739→     * Guard: mutation methods must not run after compile().
   740→     */
   741→    private function assertNotCompiled(): void
   742→    {
   743→        if ($this->compiled) {
   744→            throw new \LogicException(
   745→                'Cannot modify the container after it has been compiled.'
   746→            );
   747→        }
   748→    }
   749→
   750→    /**
   751→     * Construct an instance from the concrete binding.
   752→     *
   753→     * Dispatches on the concrete's runtime type via a match expression:
   754→     *   - Closure            -> invoke with ($container, $parameters)
   755→     *   - object (non-Closure) -> return as-is (from instance() or bind($id, $obj))
   756→     *   - class-string       -> autowire via reflection
   757→     *   - any other scalar   -> return as-is (primitive bindings)
   758→     */
   759→    private function build(mixed $concrete, array $parameters): mixed
   760→    {
   761→        return match (true) {
   762→            $concrete instanceof \Closure => $concrete($this, $parameters),
   763→            is_object($concrete) => $concrete,
   764→            is_string($concrete) && class_exists($concrete) => $this->autowire($concrete, $parameters),
   765→            default => $concrete,
   766→        };
   767→    }
   768→
   769→    /**
   770→     * Reflective autowiring.
   771→     *
   772→     * For each constructor parameter (in declaration order):
   773→     *   1. If $parameters contains the parameter name -> use the supplied value.
   774→     *   2. Else if the parameter has a default -> use the default.
   775→     *   3. Else if the parameter has a class-string type hint -> recurse into make().
   776→     *   4. Else -> throw NotFoundException (cannot resolve primitive without default).
   777→     *
   778→     * Union types, intersection types, and `readonly` properties on the
   779→     * constructor are handled implicitly by ReflectionParameter: only
   780→     * {@see \ReflectionNamedType} with isBuiltin() = false is recursed;
   781→     * everything else falls through to the default-or-throw path.
   782→     */
   783→    private function autowire(string $class, array $parameters): object
   784→    {
   785→        try {
   786→            $reflection = new \ReflectionClass($class);
   787→        } catch (\ReflectionException $e) {
   788→            throw new NotFoundException(
   789→                "Class [$class] does not exist and cannot be autowired.",
   790→                0,
   791→                $e,
   792→            );
   793→        }
   794→
   795→        if (!$reflection->isInstantiable()) {
   796→            throw new NotFoundException(
   797→                "Class [$class] is not instantiable (abstract, interface, or trait)."
   798→            );
   799→        }
   800→
   801→        $constructor = $reflection->getConstructor();
   802→
   803→        if ($constructor === null) {
   804→            return new $class();
   805→        }
   806→
   807→        $arguments = [];
   808→
   809→        foreach ($constructor->getParameters() as $parameter) {
   810→            $name = $parameter->getName();
   811→
   812→            // 1. Caller-supplied override (by name, then by position).
   813→            if (array_key_exists($name, $parameters)) {
   814→                $arguments[] = $parameters[$name];
   815→                continue;
   816→            }
   817→
   818→            $position = $parameter->getPosition();
   819→            if (array_key_exists($position, $parameters)) {
   820→                $arguments[] = $parameters[$position];
   821→                continue;
   822→            }
   823→
   824→            // 2. Default value.
   825→            if ($parameter->isDefaultValueAvailable()) {
   826→                $arguments[] = $parameter->getDefaultValue();
   827→                continue;
   828→            }
   829→
   830→            // 3. Class-string type hint -> recurse (cycle detection applies).
   831→            $type = $parameter->getType();
   832→            if ($type instanceof \ReflectionNamedType && !$type->isBuiltin()) {
   833→                $className = $type->getName();
   834→                if (class_exists($className) || interface_exists($className)) {
   835→                    $arguments[] = $this->make($className);
   836→                    continue;
   837→                }
   838→            }
   839→
   840→            // 4. Unresolvable primitive.
   841→            throw new NotFoundException(
   842→                "Cannot resolve parameter [\$$name] of [$class]: no type hint, "
   843→                . "no default value, and no caller-supplied value."
   844→            );
   845→        }
   846→
   847→        return $reflection->newInstanceArgs($arguments);
   848→    }
   849→}

   921→## Integration Strategy
   922→
   923→**Upward (what CORE-02 consumes).** The container depends only on `psr/container: ^2.0` and the PHP 8.3 standard library (`ReflectionClass`, `ReflectionNamedType`, `\Closure`, `\RuntimeException`, `\LogicException`). No other Core-tier component is invoked during resolution.
   924→
   925→**Downward (what consumes CORE-02).**
   926→
   927→1. **CORE-18 (Kernel)** is the composition root. The kernel boot sequence is:
   928→   ```php
   929→   $container = new Container();
   930→   $container->instance(Config::class, $config);   // CORE-10 built earlier
   931→   $container->singleton(LoggerInterface::class, Logger::class);
   932→   // ... register service providers (CORE-17)
   933→   foreach ($providers as $provider) {
   934→       $provider->register($container);
   935→   }
   936→   $container->compile();
   937→   $kernel = $container->get(Kernel::class);
   938→   ```
   939→   After `compile()`, the container is frozen; the kernel never mutates it again.
   940→
   941→2. **CORE-17 (Service Provider System)** wraps `ContainerInterface`. Each service provider's `register()` calls `bind()` / `singleton()` / `instance()`; an optional `boot()` runs against the compiled container (read-only). The `addCompilerPass()` hook is the extension point for providers that need to rewrite the graph (e.g. tag-based iterator compilation).
   942→
   943→3. **CORE-10 (Config)** is resolved *through* the container (registered via `instance()` early in boot, before compile). Downstream services that need configuration declare `Config $config` in their constructor and receive it via autowiring.
   944→
   945→4. **Hub-tier services** declare their dependencies as constructor type-hints. They never call `$container->get()` directly except in their own composition roots (controllers, console commands, queue workers). This keeps Hub code PSR-11-consumer-agnostic and unit-testable with a fake container.
   946→
   947→5. **Compiler passes (advanced).** A future `CompiledContainerPass` (not in this blueprint's reference implementation; tracked under CORE-17) will flatten the `$definitions` table into a cached PHP array that the container can load in production without invoking reflection. The `CompilerPassInterface` extension point is the contract that pass will implement.

   961→## CI Verification Criteria
   962→
   963→- **Branch coverage:** 100 % on `Container::make()`, `Container::autowire()`, `Container::build()`, and `Container::compile()`. Measured via PHPUnit's coverage report (`phpunit --coverage-html` against the `src/` source directory already declared in `phpunit.xml.dist`). The `match (true)` in `build()` requires four explicit tests: Closure concrete, object concrete, class-string concrete, default (scalar) concrete.
   964→- **Static analysis:** `phpstan.neon` is pre-configured at `level: max` over `src/` and `tests/`. CI runs `vendor/bin/phpstan analyse --error-format=github` and fails on any error.    971→## Security Properties
   972→
   973→1. **Circular dependency always throws `CircularDependencyException`, never stack-overflows.** The `$resolving` stack is checked before recursion; a second entry for the same id short-circuits to an exception. The chain is preserved on the exception for diagnostics. There is no code path in `make()` that can recurse without first pushing onto the stack.
   974→2. **`compile()` is idempotent-safe — further mutation throws `\LogicException`.** `assertNotCompiled()` is the first line of `bind()`, `singleton()`, `pulse()`, `instance()`, and `addCompilerPass()`. After `compile()` returns, the container is structurally immutable for the remainder of its lifetime.
   975→
   976→   **Fiber runtime note (OD-07):** `singleton()` and `pulse()` have different scope semantics under the cooperative scheduler. `singleton()` is **worker-lifetime** (shared across all concurrent Pulses in the worker process). `pulse()` is **Pulse-lifetime** (one instance per Fiber, per tenant). See `DGLAB-AS-OS-RUNTIME.md` §8.0 for the full analysis and audit requirement.
   977→3. **The resolution stack is always cleaned up via `finally`.** Even if `build()` throws (cycle, missing class, unresolvable primitive, Closure exception), the `finally` block at the end of `make()` pops the current id off `$resolving`. A failed resolution cannot leak state into the next resolution.
   978→4. **PSR-11 `get()` never silently returns null.** Unknown ids throw `NotFoundException` (implements `\Psr\Container\NotFoundExceptionInterface`). This matches the PSR-11 contract that `get()` must throw rather than return null.
   979→5. **No arbitrary code execution from external input.** The container only invokes Closures and constructors that were explicitly bound by trusted code (service providers in the kernel boot sequence). It does not deserialize, does not `eval`, does not include files. The `instance()` method accepts only `object` (not `mixed`), preventing string-coercion-based injection.
   980→6. **`has()` does not lie.** A `has($id)` returning `true` guarantees that a subsequent `get($id)` will succeed — either via a registered binding, a pre-instantiated object, or autowiring of an autoloadable class. (Caveat: autowiring may still fail at construction time if a primitive parameter is unresolvable; in that case `get()` throws `NotFoundException`, which is consistent with PSR-11.)
