    14→## Description
    15→CORE-02 is the dependency injection container that every other Core-tier service and every Hub-tier service is resolved through. It is the second object instantiated in the system kernel (CORE-18), immediately after the configuration loader (CORE-10) injects environment values. The container exposes a PSR-11 compliant `get()` / `has()` API so that any third-party PSR-11 consumer can use it unchanged, while also exposing a Sovereign-Stack-native `bind()` / `singleton()` / `make()` API that supports constructor autowiring via reflection, primitive bindings, interface-to-implementation mappings, and instance pre-registration.
    16→
    17→The container is intentionally minimal: the only runtime dependency is `psr/container: ^2.0`. No PHP-DI, no Symfony DI, no League Container. ADR-002 records the rationale — sovereign control of the resolution graph, minimal supply-chain surface, and the need for a compiler-pass architecture that flattens cleanly into the OPcache preload strategy described in ADR-010. The container has two distinct execution modes. In **open** mode (the default), `bind()`, `singleton()`, `instance()`, and `addCompilerPass()` mutate the service graph, and `make()` resolves reflectively at runtime. After `compile()` is invoked, the container enters **compiled** mode: all mutation methods throw `\LogicException`, registered compiler passes have already run, and `make()` operates against the (now-frozen) definition table. In a future revision, the compiled mode will read from a cached PHP array generated by a `CompiledContainerPass`; the present blueprint ships the open-mode + frozen-mode contract that the compiler pass extension point depends on.
    18→
    19→The container is **not** a service locator. Code that holds a reference to `ContainerInterface` should call `get()` only at composition roots (kernel boot, controller factories, console command factories). Application code is expected to receive its dependencies through constructor injection and remain container-agnostic. The container is **not** a reactive runtime by itself — the "Reactive" in its name refers to the planned integration with CORE-07/11/12 (SuperPHP), where `@persist`-scoped services will be resolved through this container; that integration is out of scope for this blueprint and tracked under CORE-12.

    65→## Architectural Design
    66→
    67→### Class Map
    68→
    69→| Class | Kind | Responsibility |
    70→|---|---|---|
    71→| `ContainerInterface` | interface | Extends `Psr\Container\ContainerInterface`. Adds `bind()`, `singleton()`, `instance()`, `make()`, `addCompilerPass()`, `compile()`. This is the API surface consumed by service providers (CORE-17) and the kernel (CORE-18). |
    72→| `ContainerBuilderInterface` | interface | Read-only view over the definition table used by compiler passes: `getDefinitions()`, `getDefinition()`, `hasDefinition()`. Decouples `CompilerPassInterface` from the mutable `Container`. |
    73→| `CompilerPassInterface` | interface | Single-method `process(ContainerBuilderInterface $builder)`. Implemented by callers (e.g. CORE-17 service providers, future `CompiledContainerPass`) to rewrite the definition graph before `compile()` freezes it. |
    74→| `ServiceDefinition` | `final readonly class` | Immutable value object: `abstract` (the bound id), `concrete` (Closure, class-string, or pre-built instance), `shared` (bool, true for singletons), `tags` (list of strings). |
    75→| `Container` | `final class` | The reference implementation. Implements `ContainerInterface` and `ContainerBuilderInterface`. Owns the `$definitions`, `$instances`, `$resolving`, `$compilerPasses`, and `$compiled` state. |
    76→| `NotFoundException` | `final class extends \RuntimeException implements \Psr\Container\NotFoundExceptionInterface` | Thrown by `get()` when the id is not resolvable. |
    77→| `CircularDependencyException` | `final class extends \RuntimeException implements \Psr\Container\ContainerExceptionInterface` | Thrown by `make()` when the resolution stack detects a cycle. Constructor takes the resolution chain array. |

    79→### Interface Contracts
    80→
    81→```php
    82→<?php
    83→declare(strict_types=1);
    84→
    85→namespace SovereignStack\Core\Container;
    86→
    87→use Psr\Container\ContainerInterface as PsrContainerInterface;
    88→
    89→/**
    90→ * Sovereign Stack dependency injection container.
    91→ *
    92→ * Extends the PSR-11 {@see PsrContainerInterface} with a mutation API
    93→ * (bind/singleton/instance/addCompilerPass/compile) and a non-cached
    94→ * factory method {@see make()} that always returns a fresh instance
    95→ * (unless the binding is marked shared, in which case the first
    96→ * resolution is cached and reused).
    97→ *
    98→ * `get()` (inherited from PSR-11) and `make()` differ in one respect:
    99→ * `get()` throws {@see NotFoundException} when the id is unknown and
   100→ * cannot be autowired; `make()` throws the same exception under the
   101→ * same conditions but is permitted to construct an unregistered
   102→ * class-string by reflection when one is supplied directly.
   103→ */
   104→interface ContainerInterface extends PsrContainerInterface
   105→{
   106→    /**
   107→     * Register a binding in the container.
   108→     *
   109→     * @param string $id        The service identifier (typically an interface FQCN).
   110→     * @param mixed  $concrete  The concrete resolver. Accepts: a class-string,
   111→     *                          a {\@see \Closure} receiving ($container, $parameters),
   112→     *                          a pre-built object instance, or null (in which case
   113→     *                          $id is used as the concrete class-string).
   114→     * @param bool   $singleton When true, the first resolved instance is cached
   115→     *                          for the **worker lifetime** and returned on all subsequent
   116→     *                          {\@see make()} / {\@see get()} calls from any Fiber/Pulse.
   117→     *
   118→     *                          **Fiber runtime warning (OD-07):** Under a long-lived
   119→     *                          FrankenPHP worker, `singleton()` means "one instance
   120→     *                          shared across ALL concurrent Pulses in this worker" —
   121→     *                          including multiple tenants. If you need per-Pulse
   122→     *                          instances (the common case for repositories, request
   123→     *                          context, tenant-scoped services), use {\@see pulse()}
   124→     *                          instead. See `DGLAB-AS-OS-RUNTIME.md` §8.0.
   125→     *
   126→     * @throws \LogicException If the container has already been compiled.
   127→     */
   128→    public function bind(string $id, mixed $concrete = null, bool $singleton = false): void;
   129→
   130→    /**
   131→     * Convenience wrapper for {\@see bind()} with $singleton = true.
   132→     *
   133→     * **Scope:** worker-lifetime (shared across all Pulses in this worker process).
   134→     * For per-Pulse instances, use {\@see pulse()}.
   135→     */
   136→    public function singleton(string $id, mixed $concrete = null): void;
   137→
   138→    /**
   139→     * Register a Pulse-scoped binding — one instance per Fiber (per Pulse).
   140→     *
   141→     * When a Pulse resolves this service, it receives a fresh instance that is
   142→     * cached for the duration of that Pulse only. A different Pulse (even in the
   143→     * same worker, even concurrently) receives its own independent instance.
   144→     *
   145→     * This is the correct scope for tenant-scoped services (repositories, unit-
   146→     * of-work, request context) under the Fiber-based cooperative runtime (OD-07).
   147→     *
   148→     * @param string $id       The service identifier.
   149→     * @param mixed  $concrete The concrete resolver (same types as {\@see bind()}).
   150→     *
   151→     * @throws \LogicException If the container has already been compiled.
   152→     */
   153→    public function pulse(string $id, mixed $concrete = null): void;
   154→
   155→    /**
   156→     * Register a pre-built object instance as a shared binding.
   157→     *
   158→     * The instance is stored in the resolved cache immediately; subsequent
   159→     * {@see get()} / {@see make()} calls return the same object identity.
   160→     *
   161→     * @param string $id       The service identifier.
   162→     * @param object $instance The instance to register.
   163→     *
   164→     * @throws \LogicException If the container has already been compiled.
   165→     */
   166→    public function instance(string $id, object $instance): void;
   167→
   168→    /**
   169→     * Resolve a service from the container.
   170→     *
   171→     * If $id refers to a shared binding that has already been resolved,
   172→     * the cached instance is returned. Otherwise a new instance is
   173→     * constructed by reflection (autowiring) using $parameters for any
   174→     * constructor arguments that cannot be resolved from the container.
   175→     *
   176→     * @param string  $id         The service identifier or a class-string.
   177→     * @param array<string,mixed> $parameters Positional-or-named constructor
   178→     *                            overrides. Named keys match parameter names;
   179→     *                            integer keys match parameter position.
   180→     *
   181→     * @return mixed The resolved service instance.
   182→     *
   183→     * @throws CircularDependencyException If $id is part of a resolution cycle.
   184→     * @throws NotFoundException           If $id cannot be resolved (unknown
   185→     *                                     class, non-instantiable class, or
   186→     *                                     an unresolved primitive constructor
   187→     *                                     argument with no default).
   188→     */
   189→    public function make(string $id, array $parameters = []): mixed;
   190→
   191→    /**
   192→     * Register a compiler pass to run during {@see compile()}.
   193→     *
   194→     * Compiler passes receive a read-only {@see ContainerBuilderInterface}
   195→     * view of the definition table and may rewrite definitions (by calling
   196→     * {@see bind()} on the underlying container) before the container is
   197→     * frozen.
   198→     *
   199→     * @throws \LogicException If the container has already been compiled.
   200→     */
   201→    public function addCompilerPass(CompilerPassInterface $pass): void;
   202→
   203→    /**
   204→     * Freeze the container.
   205→     *
   206→     * Runs all registered compiler passes in registration order, then
   207→     * sets the `$compiled` flag. After this returns, any call to
   208→     * {@see bind()}, {@see singleton()}, {@see instance()}, or
   209→     * {@see addCompilerPass()} throws {@see \LogicException}.
   210→     *
   211→     * Idempotent: calling compile() on an already-compiled container
   212→     * returns immediately without re-running passes.
   213→     */
   214→    public function compile(): void;
   215→}

   341→
   342→/**
   343→ * Thrown by {@see ContainerInterface::make()} when the resolution stack
   344→ * detects that the requested service is already being resolved higher up
   345→ * the call chain — i.e. a circular dependency.
   346→ *
   347→ * The full resolution chain is preserved in the exception so callers can
   348→ * log, display, or assert on it. The chain always ends with the id that
   349→ * closed the cycle, e.g. `[A, B, C, B]` for the cycle B → C → B reached
   350→ * while resolving A.
   351→ */
   352→final class CircularDependencyException extends \RuntimeException implements \Psr\Container\ContainerExceptionInterface
   353→{
   354→    /**
   355→     * @param list<string>  $chain    The resolution chain, in order, ending
   356→     *                                with the id that closed the cycle.
   357→     * @param string|null   $message  Optional custom message; defaults to
   358→     *                                a human-readable rendering of $chain.
   359→     * @param int           $code     Numeric code.
   360→     * @param \Throwable|null $previous Previous exception, if any.
   361→     */
   362→    public function __construct(
   363→        private readonly array $chain,
   364→        ?string $message = null,
   365→        int $code = 0,
   366→        ?\Throwable $previous = null,
   367→    ) {
   368→        parent::__construct(
   369→            $message ?? 'Circular dependency detected: ' . implode(' -> ', $chain),
   370→            $code,
   371→            $previous,
   372→        );
   373→    }
   374→
   375→    /**
   376→     * Convenience factory.
   377→     *
   378→     * @param list<string> $chain
   379→     */

   381→    {

   383→    }
   384→
   385→    /**

   387→     */

   391→    }

   395→### Reference Implementation
   396→
   397→The following class is the complete, copy-pasteable `Container` implementation. It compiles against PHP 8.3 with only `psr/container: ^2.0` as runtime dependency. Drop it into `packages/core/container/src/Container.php` alongside the interface files above and `composer dump-autoload` will pick it up unchanged.
   398→
   399→```php
   400→<?php
   401→declare(strict_types=1);
   402→
   403→namespace SovereignStack\Core\Container;
   404→
   405→/**
   406→ * Reference implementation of {@see ContainerInterface} and
   407→ * {@see ContainerBuilderInterface}.
   408→ *
   409→ * State:
   410→ *   - $definitions    : id -> ServiceDefinition (the binding table)
   411→ *   - $instances      : id -> resolved object (shared-instance cache)
   412→ *   - $pulseInstances : WeakMap<Fiber, array<string, mixed>> (auto-evicts on Fiber GC)
   413→ *   - $resolving      : id -> true (the resolution stack; presence == on stack)
   414→ *   - $compilerPasses : list of passes to run during compile()
   415→ *   - $compiled       : freeze flag; mutation methods assert false before running
   416→ *
   417→ * Resolution flow (see also the sequence diagram in this blueprint):
   418→ *   make(A) ->
   419→ *     1. if A in $instances -> return cached object
   420→ *     1b. if A is pulse-scoped && current Fiber -> check WeakMap[Fiber][A]
   421→ *     2. if A in $resolving -> throw CircularDependencyException(chain)
   422→ *     3. push A onto $resolving
   423→ *     4. try { build(concrete) } finally { pop A from $resolving }
   424→ *     5. if shared -> cache in $instances
   425→ *     5b. if pulse-scoped && current Fiber -> cache in WeakMap[Fiber][A]
   426→ *     6. return object
   427→ *
   428→ * Cycle detection is resolution-time, not graph-time. This is deliberate:
   429→ * a graph-time analysis would have to walk every Closure binding (which may
   430→ * be opaque) and every constructor argument of every class. Resolution-time
   431→ * detection via a stack + finally is O(depth) per resolution, never
   432→ * stack-overflows, and surfaces the exact chain that closed the cycle.
   433→ */
   434→final class Container implements ContainerInterface, ContainerBuilderInterface
   435→{
   436→    /** @var array<string, ServiceDefinition> */
   437→    private array $definitions = [];
   438→
   439→    /** @var array<string, mixed> Worker-scoped instance cache (singleton + instance). */
   440→    private array $instances = [];
   441→
   442→    /**
   443→     * Pulse-scoped instance cache, keyed on the Fiber object itself.
   444→     * WeakMap<Fiber, array<string, mixed>> — auto-evicts when Fiber is GC'd.
   445→     * Outside any Fiber context, pulse-scoped bindings behave as transient.
   446→     */
   447→    private \WeakMap $pulseInstances;
   448→
   449→    /** @var array<string, true> */
   450→    private array $resolving = [];
   451→
   452→    /** @var list<CompilerPassInterface> */
   453→    private array $compilerPasses = [];
   454→
   455→    private bool $compiled = false;
   456→
   457→    public function __construct()
   458→    {
   459→        $this->pulseInstances = new \WeakMap();
   460→    }
   461→
   462→    public function bind(string $id, mixed $concrete = null, bool $singleton = false): void
   463→    {
   464→        $this->assertNotCompiled();
   465→
   466→        $concrete ??= $id;
   467→
   468→        $this->definitions[$id] = new ServiceDefinition(
   469→            abstract: $id,
   470→            concrete: $concrete,
   471→            shared: $singleton,
   472→            tags: [],
   473→        );
   474→    }
   475→
   476→    public function singleton(string $id, mixed $concrete = null): void
   477→    {
   478→        $this->bind($id, $concrete, true);
   479→    }
   480→
   481→    public function pulse(string $id, mixed $concrete = null): void
   482→    {
   483→        $this->assertNotCompiled();
   484→
   485→        $concrete ??= $id;
   486→
   487→        $this->definitions[$id] = new ServiceDefinition(
   488→            abstract: $id,
   489→            concrete: $concrete,
   490→            shared: false,
   491→            pulseScoped: true,
   492→            tags: [],
   493→        );
   494→    }
   495→
   496→    public function instance(string $id, object $instance): void
   497→    {
   498→        $this->assertNotCompiled();
   499→
   500→        $this->instances[$id] = $instance;
   501→        $this->definitions[$id] = new ServiceDefinition(
   502→            abstract: $id,
   503→            concrete: $instance,
   504→            shared: true,
   505→            tags: [],
   506→        );
   507→    }
   508→
   509→    public function make(string $id, array $parameters = []): mixed
   510→    {
   511→        // 1. Resolved-instance cache (worker-scoped).
   512→        if (array_key_exists($id, $this->instances)) {
   513→            return $this->instances[$id];
   514→        }
   515→
   516→        // 1b. Pulse-scoped cache (WeakMap — auto-evicts on Fiber GC).
   517→        $definition = $this->definitions[$id] ?? null;
   518→        if ($definition !== null && $definition->pulseScoped) {
   519→            $fiber = \Fiber::getCurrent();
   520→            if ($fiber !== null && isset($this->pulseInstances[$fiber][$id])) {
   521→                return $this->pulseInstances[$fiber][$id];
   522→            }
   523→        }
   524→
   525→        // 2. Cycle detection — resolution-time, never stack-overflows.
   526→        if (isset($this->resolving[$id])) {
   527→            $chain = array_keys($this->resolving);
   528→            $chain[] = $id;
   529→            throw CircularDependencyException::fromChain($chain);
   530→        }
   531→
   532→        // 3. Push onto the resolution stack.
   533→        $this->resolving[$id] = true;
   534→
   535→        try {
   536→            $concrete = $definition?->concrete ?? $id;
   537→
   538→            // 4. Build by concrete type.
   539→            $object = $this->build($concrete, $parameters);
   540→        } finally {
   541→            // 5. Always pop, even on exception — no state leak.
   542→            unset($this->resolving[$id]);
   543→        }
   544→
   545→        // 6. Cache shared singletons (worker-scoped).
   546→        if ($definition !== null && $definition->shared) {
   547→            $this->instances[$id] = $object;
   548→        }
   549→
   550→        // 6b. Cache pulse-scoped instances (per-Fiber, via WeakMap).
   551→        if ($definition !== null && $definition->pulseScoped) {
   552→            $fiber = \Fiber::getCurrent();
   553→            if ($fiber !== null) {
   554→                $this->pulseInstances[$fiber][$id] = $object;
   555→            }
   556→        }
   557→
   558→        return $object;
   559→    }
   560→
   561→    /**
   562→     * PSR-11 get(): throws NotFoundException on unknown ids.
   563→     *
   564→     * Unlike make(), get() refuses to construct an arbitrary class-string
   565→     * that has not been explicitly bound or registered via instance().
   566→     * This matches the PSR-11 contract that get() must throw if the id
   567→     * is not "known" to the container.
   568→     */
   569→    public function get(string $id): mixed
   570→    {
   571→        if (!$this->has($id)) {
   572→            throw new NotFoundException("No service registered for id [$id].");
   573→        }
   574→
   575→        return $this->make($id);
   576→    }
   577→
   578→    /**
   579→     * PSR-11 has(): true if the id is bound, pre-instantiated, or
   580→     * refers to an autoloadable class (the latter supports autowiring
   581→     * of unregistered class-strings via make()).
   582→     */
   583→    public function has(string $id): bool
   584→    {
   585→        return array_key_exists($id, $this->instances)
   586→            || array_key_exists($id, $this->definitions)
   587→            || class_exists($id);
   588→    }
   589→
   590→    public function addCompilerPass(CompilerPassInterface $pass): void
   591→    {
   592→        $this->assertNotCompiled();
   593→        $this->compilerPasses[] = $pass;
   594→    }
   595→
   596→    public function compile(): void
   597→    {
   598→        // Idempotent: a second call is a no-op.
   599→        if ($this->compiled) {
   600→            return;
   601→        }
   602→
   603→        foreach ($this->compilerPasses as $pass) {
   604→            $pass->process($this);
   605→        }
   606→
   607→        $this->compiled = true;
   608→    }
   609→
   610→    // ----- ContainerBuilderInterface -----
   611→
   612→    public function getDefinitions(): array
   613→    {
   614→        return $this->definitions;
   615→    }
   616→
   617→    public function getDefinition(string $id): ServiceDefinition
   618→    {
   619→        if (!array_key_exists($id, $this->definitions)) {
   620→            throw new NotFoundException("No definition registered for id [$id].");
   621→        }
   622→
   623→        return $this->definitions[$id];
   624→    }
   625→
   626→    public function hasDefinition(string $id): bool
   627→    {
   628→        return array_key_exists($id, $this->definitions);
   629→    }
   630→
   631→    // ----- Internals -----
   632→
   633→    /**
   634→     * Guard: mutation methods must not run after compile().
   635→     */
   636→    private function assertNotCompiled(): void
   637→    {
   638→        if ($this->compiled) {
   639→            throw new \LogicException(
   640→                'Cannot modify the container after it has been compiled.'
   641→            );
   642→        }
   643→    }
   644→
   645→    /**
   646→     * Construct an instance from the concrete binding.
   647→     *
   648→     * Dispatches on the concrete's runtime type via a match expression:
   649→     *   - Closure            -> invoke with ($container, $parameters)
   650→     *   - object (non-Closure) -> return as-is (from instance() or bind($id, $obj))
   651→     *   - class-string       -> autowire via reflection
   652→     *   - any other scalar   -> return as-is (primitive bindings)
   653→     */
   654→    private function build(mixed $concrete, array $parameters): mixed
   655→    {
   656→        return match (true) {
   657→            $concrete instanceof \Closure => $concrete($this, $parameters),
   658→            is_object($concrete) => $concrete,
   659→            is_string($concrete) && class_exists($concrete) => $this->autowire($concrete, $parameters),
   660→            default => $concrete,
   661→        };
   662→    }
   663→
   664→    /**
   665→     * Reflective autowiring.
   666→     *
   667→     * For each constructor parameter (in declaration order):
   668→     *   1. If $parameters contains the parameter name -> use the supplied value.
   669→     *   2. Else if the parameter has a default -> use the default.
   670→     *   3. Else if the parameter has a class-string type hint -> recurse into make().
   671→     *   4. Else -> throw NotFoundException (cannot resolve primitive without default).
   672→     *
   673→     * Union types, intersection types, and `readonly` properties on the
   674→     * constructor are handled implicitly by ReflectionParameter: only
   675→     * {@see \ReflectionNamedType} with isBuiltin() = false is recursed;
   676→     * everything else falls through to the default-or-throw path.
   677→     */
   678→    private function autowire(string $class, array $parameters): object
   679→    {
   680→        try {
   681→            $reflection = new \ReflectionClass($class);
   682→        } catch (\ReflectionException $e) {
   683→            throw new NotFoundException(
   684→                "Class [$class] does not exist and cannot be autowired.",
   685→                0,
   686→                $e,
   687→            );
   688→        }
   689→
   690→        if (!$reflection->isInstantiable()) {
   691→            throw new NotFoundException(
   692→                "Class [$class] is not instantiable (abstract, interface, or trait)."
   693→            );
   694→        }
   695→
   696→        $constructor = $reflection->getConstructor();
   697→
   698→        if ($constructor === null) {
   699→            return new $class();
   700→        }
   701→
   702→        $arguments = [];
   703→
   704→        foreach ($constructor->getParameters() as $parameter) {
   705→            $name = $parameter->getName();
   706→
   707→            // 1. Caller-supplied override (by name, then by position).
   708→            if (array_key_exists($name, $parameters)) {
   709→                $arguments[] = $parameters[$name];
   710→                continue;
   711→            }
   712→
   713→            $position = $parameter->getPosition();
   714→            if (array_key_exists($position, $parameters)) {
   715→                $arguments[] = $parameters[$position];
   716→                continue;
   717→            }
   718→
   719→            // 2. Default value.
   720→            if ($parameter->isDefaultValueAvailable()) {
   721→                $arguments[] = $parameter->getDefaultValue();
   722→                continue;
   723→            }
   724→
   725→            // 3. Class-string type hint -> recurse (cycle detection applies).
   726→            $type = $parameter->getType();
   727→            if ($type instanceof \ReflectionNamedType && !$type->isBuiltin()) {
   728→                $className = $type->getName();
   729→                if (class_exists($className) || interface_exists($className)) {
   730→                    $arguments[] = $this->make($className);
   731→                    continue;
   732→                }
   733→            }
   734→
   735→            // 4. Unresolvable primitive.
   736→            throw new NotFoundException(
   737→                "Cannot resolve parameter [\$$name] of [$class]: no type hint, "
   738→                . "no default value, and no caller-supplied value."
   739→            );
   740→        }
   741→
   742→        return $reflection->newInstanceArgs($arguments);
   743→    }
   744→}
   745→```

   816→## Integration Strategy
   817→
   818→**Upward (what CORE-02 consumes).** The container depends only on `psr/container: ^2.0` and the PHP 8.3 standard library (`ReflectionClass`, `ReflectionNamedType`, `\Closure`, `\RuntimeException`, `\LogicException`). No other Core-tier component is invoked during resolution.
   819→
   820→**Downward (what consumes CORE-02).**
   821→
   822→1. **CORE-18 (Kernel)** is the composition root. The kernel boot sequence is:
   823→   ```php
   824→   $container = new Container();
   825→   $container->instance(Config::class, $config);   // CORE-10 built earlier
   826→   $container->singleton(LoggerInterface::class, Logger::class);
   827→   // ... register service providers (CORE-17)
   828→   foreach ($providers as $provider) {
   829→       $provider->register($container);
   830→   }
   831→   $container->compile();
   832→   $kernel = $container->get(Kernel::class);
   833→   ```
   834→   After `compile()`, the container is frozen; the kernel never mutates it again.
   835→
   836→2. **CORE-17 (Service Provider System)** wraps `ContainerInterface`. Each service provider's `register()` calls `bind()` / `singleton()` / `instance()`; an optional `boot()` runs against the compiled container (read-only). The `addCompilerPass()` hook is the extension point for providers that need to rewrite the graph (e.g. tag-based iterator compilation).
   837→
   838→3. **CORE-10 (Config)** is resolved *through* the container (registered via `instance()` early in boot, before compile). Downstream services that need configuration declare `Config $config` in their constructor and receive it via autowiring.
   839→
   840→4. **Hub-tier services** declare their dependencies as constructor type-hints. They never call `$container->get()` directly except in their own composition roots (controllers, console commands, queue workers). This keeps Hub code PSR-11-consumer-agnostic and unit-testable with a fake container.
   841→
   842→5. **Compiler passes (advanced).** A future `CompiledContainerPass` (not in this blueprint's reference implementation; tracked under CORE-17) will flatten the `$definitions` table into a cached PHP array that the container can load in production without invoking reflection. The `CompilerPassInterface` extension point is the contract that pass will implement.

   856→## CI Verification Criteria
   857→
   858→- **Branch coverage:** 100 % on `Container::make()`, `Container::autowire()`, `Container::build()`, and `Container::compile()`.    861→- **Cycle detection test:** an explicit `tests/Unit/CircularDependencyTest.php` that registers two classes that depend on each other and asserts that `make()` throws `CircularDependencyException` whose `getResolutionChain()` returns the expected chain (e.g. `[A, B, A]`).

Dev dependencies (test suites, phpstan) may be added freely under `require-dev`.

   866→## Security Properties
   867→
   868→1. **Circular dependency always throws `CircularDependencyException`, never stack-overflows.** The `$resolving` stack is checked before recursion; a second entry for the same id short-circuits to an exception. The chain is preserved on the exception for diagnostics. There is no code path in `make()` that can recurse without first pushing onto the stack.
   869→2. **`compile()` is idempotent-safe — further mutation throws `\LogicException`.** `assertNotCompiled()` is the first line of `bind()`, `singleton()`, `pulse()`, `instance()`, and `addCompilerPass()`. After `compile()` returns, the container is structurally immutable for the remainder of its lifetime.
   870→
   871→   **Fiber runtime note (OD-07):** `singleton()` and `pulse()` have different scope semantics under the cooperative scheduler. `singleton()` is **worker-lifetime** (shared across all concurrent Pulses in the worker process). `pulse()` is **Pulse-lifetime** (one instance per Fiber, per tenant). See `DGLAB-AS-OS-RUNTIME.md` §8.0 for the full analysis and audit requirement.
   872→3. **The resolution stack is always cleaned up via `finally`.** Even if `build()` throws (cycle, missing class, unresolvable primitive, Closure exception), the `finally` block at the end of `make()` pops the current id off `$resolving`. A failed resolution cannot leak state into the next resolution.
   873→4. **PSR-11 `get()` never silently returns null.** Unknown ids throw `NotFoundException` (implements `\Psr\Container\NotFoundExceptionInterface`). This matches the PSR-11 contract that `get()` must throw rather than return null.
   874→5. **No arbitrary code execution from external input.** The container only invokes Closures and constructors that were explicitly bound by trusted code (service providers in the kernel boot sequence). It does not deserialize, does not `eval`, does not include files. The `instance()` method accepts only `object` (not `mixed`), preventing string-coercion-based injection.
   875→6. **`has()` does not lie.** A `has($id)` returning `true` guarantees that a subsequent `get($id)` will succeed — either via a registered binding, a pre-instantiated object, or autowiring of an autoloadable class. (Caveat: autowiring may still fail at construction time if a primitive parameter is unresolvable; in that case `get()` throws `NotFoundException`, which is consistent with PSR-11.)
